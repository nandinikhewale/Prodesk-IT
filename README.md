# Prodesk IT — Digital Marketing Website

Responsive, accessible and performant marketing website for Prodesk IT.

## Preview

https://prodeskit-flame.vercel.app/

## Summary

Prodesk IT is a single page website created to display the company's services, methodology, values, frequently asked questions and contact details. The website is built with accessibility and performance in mind.

## Key features

### Responsive design

The website is responsive and looks good on all types of devices.

It uses CSS Grid and Flexbox and is fully accessible.

### Accessibility

The website is accessible and uses contrast colors.

The navigation bar changes into a hamburger menu on smaller screens.

The hamburger menu can be opened and closed with a button.

The button has an aria-expanded attribute.

The menu closes when the user clicks anywhere outside of it.

### Dark / Light mode

The website has a dark/light toggle switch.

The theme is saved in local storage.

The website uses prefers-color-scheme

### Performance

The website is fast, optimized and built with best practices in mind.

There are a lot of performance enhancements.

All assets are minified.

## Technologies used

JavaScript, CSS, HTML, Vercel

This is a marketing website that showcases Prodesk IT's services. I tried to make it as performant as possible. I used many optimizations to make the website load faster. The code is clean and well organized.
